## 主要功能

- 本地保存 Trae CN 账号认证快照，不修改 Trae CN 安装目录，不修改 `app.asar`。
- 多账号一键切换，事务式文件替换，失败自动回滚。
- 无感登录：浏览器完成授权后，新账号自动加入列表，并立即同步套餐、余额与签到状态。
- 假退出登录：备份当前账号后进入 Trae CN 登录页，登录成功后自动保存新账号。
- 账号导出使用用户密码加密（scrypt + AES-256-GCM），导入不会自动切换当前账号。
- 自动签到支持 15、30、60、120 分钟间隔，每个账号使用独立的 `userId` 作为设备标识。
- 自动维护登录信息：只在临近到期时更新，平时复用现有凭据，降低把其他设备顶下线的概率。
- 面板查看每个账号的手机号、套餐、余额、签到状态和登录信息有效期。
- 非当前账号支持删除本地备份；当前正在使用的账号受到保护。
- 设置页按「签到 / 更新 / 维护」分组，避免所有配置堆在同一页。
- 关于页改为面向普通用户的添加、切换、迁移和数据安全说明。

## 安装

运行 `TraeCodeEnhancer-Setup-1.0.0.exe`。安装是 per-user 的，不需要管理员权限，目录页保留可改。

安装向导会严格检测 Trae CN 主程序。如果检测错误或失败，手动选择 `Trae CN.exe`（文件名必须完全匹配，否则会被拒绝）。选择路径通过 `TraeCodeEnhancer.exe configure` 命令行保存，避免 ANSI 解码中文路径损坏。

因构建未签名，Windows SmartScreen 可能警告未知发布者。安装前请先核对 SHA-256。

## 升级和重装

直接运行新版安装包覆盖安装即可。安装程序保留稳定的 AppId、上次安装目录和上次附加任务选择。替换文件前会先停止旧的后台服务。`data\` 目录会保留。

## 卸载

交互式卸载会询问是否保留 `data\`。静默卸载默认保留用户数据。

`data\` 包含账号认证快照、API token 和本地配置。删除后不可恢复。

## 已知限制

- 安装包未签名，Windows SmartScreen 可能提示风险。
- 当前没有在线自动更新功能，升级需要覆盖运行新版安装包。
- 导入导出属于账号迁移，不是多设备共享。原设备继续更新登录信息后，副本可能失效并需要重新登录。
- 当前仅支持 Windows 10/11 x64 和 Trae CN。
- 与 TRAE SOLO CN 增强助手（TraeWork）共享大部分代码，端口错开：本助手 UI `47836` / CDP `9336`，TraeWork 助手 `47835` / `9335`，两者可同时运行。
- 自动签到未登录时显示「TRAE 尚未登录」；无感登录和假退出新增账号后会立即同步签到、套餐和余额。
